# JLZ-EDU-SK-097 Codex执行任务书

## 1. 基线

- 任务编号：`JLZ-EDU-EXPANSION-30-FULL-DELIVERY`
- 候选来源：`CAND-055`
- 正式产品：`JLZ-EDU-SK-097` / 课程版本发布检查
- 类型：Skill
- 批次：2

- 版本基线：`EDUCATION_BASELINE_V1.0.0`
- 产品版本：`1.0.0`
- 许可证：Apache-2.0

## 2. 用户、痛点与目标

- 用户：课程产品经理、教研负责人、质量审核员、运营负责人
- 痛点：课程更新常涉及目标、课件、练习、价格、教师培训和营销物料，版本不同步会在开课后暴露。
- 目标：设置课程上线门禁，逐项检查内容、评估、材料、系统、培训、价格、版权和运营准备度。

|---|---|---|---|

| `syllabus` | 课程大纲 | string | 是 |

| `assessments` | 测评与答案 | array | 是 |

## 4. 工作流

1. 冻结版本范围
2. 核对产品契约
3. 检查内容与评估
4. 验证材料和培训
5. 检查系统与价格
6. 出放行/阻断结论

## 5. 阶段状态

| 阶段 | 动作 | 退出成果 |
|---|---|---|
| S1_SCOPE_CONFIRMATION | 确认目标、校区/岗位/课程范围、期限、交付格式和可用资料。 | 任务确认单与最多3个关键缺口 |
| S2_EVIDENCE_INVENTORY | 盘点课程版本、目标与大纲、课件/练习/答案、教师培训、系统配置、价格/合同、营销物料、上线日期，标记来源、版本、敏感字段与冲突。 | 证据清单、缺口表和冲突表 |
| S3_PROFESSIONAL_DIAGNOSIS | 围绕设置课程上线门禁，逐项检查内容、评估、材料、系统、培训、价格、版权和运营准备度。进行专业诊断，形成问题树和优先级。 | 问题树、风险和优先级 |
| S4_SOLUTION_DESIGN | 按冻结版本范围 → 核对产品契约 → 检查内容与评估 → 验证材料和培训 → 检查系统与价格 → 出放行/阻断结论设计首选方案和受限备选方案。 | 方案、责任人、完成标准 |
| S5_HUMAN_CONFIRMATION | 由业务负责人复核输入事实、关键假设和最终成果适用范围。 | 确认记录、未决项和升级项 |
| S6_FINAL_DELIVERY | 生成完整交付成果，执行结构、证据、安全、品牌和独立安装检查。 | 最终成果、范围限制和复盘指标 |

## 6. 核心成果

- `发布就绪报告`
- `阻断项`
- `上线批准单`

## 7. 差异化与排重

- 与现有产品：课程体系开发负责设计课程；本产品对已完成版本做独立发布门禁，不修改课程设计。
- 排重检查：部分重叠；共享课程材料，但输出上线检查与放行/阻断，不开发课程。
- 独立理由：对任何人工或AI生成课程均可独立检查。

## 8. 安全与人工门禁

- 复核角色：业务负责人
- 复核范围：输入事实、关键假设和最终成果适用范围
- 不调用外部收费API。
- 不自动修改外部系统、执行退款、审批合同、处分员工或联系外部人员。
- 高风险产品完成状态必须确认人工复核。
