# 课程版本发布检查领域指南

## 业务问题

课程更新常涉及目标、课件、练习、价格、教师培训和营销物料，版本不同步会在开课后暴露。

## 产品解决方案

设置课程上线门禁，逐项检查内容、评估、材料、系统、培训、价格、版权和运营准备度。

## 输入质量要求

| 字段 | 名称 | 必填 | 质量要求 |
|---|---|---|---|
| `course_version` | 课程版本 | 是 | 版本号与发布范围 |
| `learning_objectives` | 学习目标 | 是 | 课程目标 |
| `syllabus` | 课程大纲 | 是 | 课时和内容结构 |
| `materials` | 课件与练习材料 | 是 | 文件清单和版本 |
| `assessments` | 测评与答案 | 是 | 与课程目标的对应 |
| `teacher_training` | 教师培训准备 | 是 | 培训与评分标准 |
| `system_configuration` | 系统配置 | 否 | 课程、班级、价格、权限 |
| `pricing_contracts` | 价格与合同 | 是 | 上线售价和合同口径 |
| `marketing_assets` | 营销素材 | 是 | 上线所需宣传物料 |
| `launch_date` | 计划上线日期 | 是 | ISO 日期或明确日期口径 |

## 证据判断

- 用户原文优先于模型推断。
- 外部政策或公开事实应记录标题、发布机构、发布日期、URL、访问日期和适用范围。
- 无法核验时标记`EVIDENCE_UNVERIFIED`，不补造来源。
- 数据冲突必须并列展示，并说明对结论的影响。

## 人工复核

业务负责人应确认：输入事实、关键假设和最终成果适用范围。未经确认的内容只能作为草案。

## 主要风险

不能替代教研和法务审批；发布证据必须真实；高风险内容需人工确认。
